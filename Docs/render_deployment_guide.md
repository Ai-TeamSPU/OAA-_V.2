> **หัวข้อ:** การรันหลังบ้าน (Backend API) บน Render.com พฤติกรรม 24/7 และวิธีทำให้ระบบตื่นตลอดเวลาโดยไม่มีค่าใช้จ่าย

## 📊 1. เปรียบเทียบพฤติกรรมระหว่างแพ็กเกจฟรี vs แพ็กเกจเสียเงิน

| หัวข้อ | แพ็กเกจฟรี (Free Plan) | แพ็กเกจเสียเงิน ($7/เดือน) |
| :--- | :--- | :--- |
| **การออนไลน์ 24/7** | 🟢 ออนไลน์ตลอด 24 ชม. | 🟢 ออนไลน์ตลอด 24 ชม. |
| **โควตาเวลาสะสม** | 750 ชั่วโมง/เดือน (เพียงพอสำหรับ 1 แอป 24/7) | ไม่จำกัด |
| **พฤติกรรมเมื่อไม่มีคนใช้** | หากไม่มี Request เกิน 15 นาที ระบบจะ **จำศีล (Sleep)** | ทำงานต่อเนื่องตลอดเวลา **ไม่มีจำศีล** |
| **ระยะเวลาตอบกลับครั้งแรก** | หากเพิ่งตื่น จะใช้เวลา 30–50 วินาที (Cold Start) | ตอบกลับทันทีในมิลลิวินาที (< 100ms) |
| **ค่าใช้จ่าย** | 💵 **0 บาท (ฟรีตลอดชีพ)** | 💵 ประมาณ 250 บาท/เดือน |

## ⚡ 2. กลไกการจำศีล (Cold Start) ของแพ็กเกจฟรีทำงานอย่างไร?

```
[ไม่มีการใช้งาน 15 นาที] ──► [API เข้าสู่โหมดจำศีล Sleep]
                                      │
                                      ▼
                               [ผู้ใช้คนแรกเปิดหน้าเว็บ]
                                      │
                                      ▼
                      [Render ปลุก API ให้ตื่น (30-50 วินาที)]
                                      │
                                      ▼
                     [API ตื่นแล้ว ──► ทำงานเร็วปกติ 100%]
```

1. เมื่อไม่มีผู้ใช้งานเกิน 15 นาที Render จะสั่งปิดกระบวนการชั่วคราวเพื่อประหยัด RAM/CPU
2. เมื่อผู้ใช้งานคนแรกเปิดหน้าเว็บ Netlify/Vercel ระบบจะยิงไปหา `GET /api/health`
3. ในครั้งแรกนี้ หน้าเว็บอาจขึ้นโหลดหมุนประมาณ 30-50 วินาที เพื่อรอหลังบ้านสตาร์ทตัวเอง
4. เมื่อตื่นแล้ว ผู้ใช้งานคนถัดไปจะใช้งานได้เร็วราบรื่นทันที

## 🛠️ 3. เทคนิคทำให้แพ็กเกจฟรี "ตื่นอยู่ตลอดเวลา 24 ชั่วโมง" (0 บาท)

หากต้องการให้แพ็กเกจฟรีทำงานเร็วทันทีตลอดเวลาโดย **ไม่ต้องรอนาน 30 วินาที** สามารถทำได้ด้วยการสะกิด API ทุกๆ 10 นาทีดังนี้ครับ:

### วิธีทำผ่านเว็บ UptimeRobot (ฟรี):
1. สมัครใช้งานเว็บไซต์ฟรีที่ **[UptimeRobot.com](https://uptimerobot.com)**
2. กดปุ่ม **"Add New Monitor"**
3. ตั้งค่าดังนี้:
   * **Monitor Type:** `HTTP(s)`
   * **Friendly Name:** `OAA Backend Ping`
   * **URL (or IP):** ใส่ลิงก์ `https://your-backend.onrender.com/api/health`
   * **Monitoring Interval:** ทุกๆ `5 minutes` หรือ `10 minutes`
4. กด **Create Monitor**

> **ผลลัพธ์:** UptimeRobot จะยิงทักทายไปที่ `/api/health` หลังบ้านของคุณทุกๆ 5 นาที ทำให้ Render คิดว่ามีคนใช้อยู่ตลอดเวลา และ **จะไม่ยอมจำศีลเลยตลอด 24 ชั่วโมง!**

## 🚀 4. สรุปขั้นตอนการ Deploy โฟลเดอร์ `pageback` บน Render.com

1. เข้าเว็บไซต์ **[Render.com](https://render.com)** ➔ ล็อกอินด้วย **GitHub**
2. กดปุ่ม **"New +"** ➔ เลือก **"Web Service"**
3. เลือก Repository **`Ai-TeamSPU/OAA-_V.2`**
4. ตั้งค่าหน้าต่าง Build ดังนี้:
   * **Name:** `oaa-backend-api`
   * **Root Directory:** `pageback` *(สำคัญมาก!)*
   * **Environment:** `Node`
   * **Build Command:** `npm install`
   * **Start Command:** `node server.js`
5. เพิ่มตัวแปรสภาพแวดล้อม (Environment Variables) จากไฟล์ `.env`:
   * `SUPABASE_URL` = (URL ของ Supabase)
   * `SUPABASE_KEY` = (Anon Key ของ Supabase)
   * `JWT_SECRET` = (Secret Key สำหรับ JWT)
   * `ADMIN_PASSWORD` = (รหัสผ่าน Admin)
   * `ALLOWED_ORIGINS` = `https://oaa-save-data-techerspacial-v2.netlify.app,https://oaa-v2.vercel.app`
6. กด **Create Web Service** ➔ ได้รับ URL หลังบ้านมาใช้งานทันที!
