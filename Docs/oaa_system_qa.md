## 2. ฐานข้อมูล Supabase / ระบบเขียนด้วยภาษาอะไร? (Tech Stack & Languages)

โครงสร้างซอฟต์แวร์ของโปรเจกต์แบ่งออกเป็น 3 เลเยอร์หลักตามมาตรฐานการพัฒนาเว็บแอปพลิเคชันยุคใหม่:

### 2.1 ฐานข้อมูล (Database Layer)
* **ภาษาฐานข้อมูล:** **SQL (Structured Query Language)** 
* **Database Engine:** **PostgreSQL 15.x / 16.x** บนบริการคลาวด์ **Supabase**
* **โครงสร้างตาราง (Normalized Schema):** ออกแบบตารางแยกอย่างชัดเจนเป็น **5 ตารางความสัมพันธ์ (Relational 1:M)** ใช้ชนิดข้อมูล ID เป็นตัวเลขรันอัตโนมัติ (`BIGINT Auto-Increment` 1, 2, 3...) ได้แก่:
  1. `instructors` (ตารางหลักเก็บประวัติส่วนตัวและข้อมูลทั่วไป)
  2. `instructor_educations` (ตารางย่อยเก็บประวัติการศึกษา)
  3. `instructor_experiences` (ตารางย่อยเก็บประวัติการทำงาน)
  4. `instructor_awards` (ตารางย่อยเก็บรางวัลและผลงาน)
  5. `instructor_courses` (ตารางย่อยเก็บรายวิชาเสนอสอน)

### 2.2 ระบบหลังบ้าน / API Server (Backend Layer)
* **ภาษาโปรแกรมมิ่ง:** **JavaScript (Node.js)**
* **Framework:** **Express.js (v4.19)** ร่วมกับ `@supabase/supabase-js` (v2.43)
* **หน้าที่และความปลอดภัย:** ประมวลผลกระจายข้อมูลลง 5 ตารางย่อย, ตรวจสอบความสะอาดของข้อมูล (Input Sanitization/XSS), กำหนด HTTP Security Headers (Helmet), จำกัดอัตราเรียกใช้งาน (Rate Limiting) และบันทึกประวัติการใช้งาน (Audit Trail Logs)

### 2.3 หน้าเว็บส่วนหน้า (Frontend Layer)
* **ภาษาโปรแกรมมิ่ง:** **JavaScript (ES6+ / JSX)** ร่วมกับ **HTML5** และ **CSS3**
* **Framework / Library:** **React** (ใช้ Babel Standalone) และแบบฟอร์มพิมพ์เอกสารทางการ (`index-print.html`)

## 3. การ Login เข้าระบบ มีหรือไม่ ใช้ User อะไร อย่างไร?

### 3.1 รูปแบบและนโยบายการเข้าถึงระบบ (PDPA Security Compliance)
* **สำหรับอาจารย์พิเศษ (ผู้กรอกข้อมูล):** **ไม่ต้อง Login** เพื่อให้อาจารย์ได้รับความสะดวกสูงสุด สามารถเปิดลิงก์หรือสแกน QR Code เข้ามากรอกประวัติส่วนตัวและส่งข้อมูลได้ทันที 0 คลิก
* **สำหรับเจ้าหน้าที่ / Admin (ผู้จัดการประวัติ):** **มีระบบ Login บังคับ 100%** เพื่อปกป้องข้อมูลส่วนบุคคลของอาจารย์พิเศษตามกฎหมาย PDPA ป้องกันไม่ให้บุคคลภายนอกเข้าถึงเบอร์โทร ที่อยู่ หรือเอกสารส่วนตัว

### 3.2 รายละเอียดและวิธีการ Login เข้าระบบ
1. **วิธีการเข้าสู่ระบบ:** กดปุ่ม **`🔐 Admin`** ที่มุมขวาบนของหน้าเว็บ
2. **ระบบการยืนยันตัวตน:** ระบบใช้ **Single Administrative Password Authentication** ผูกกับเทคโนโลยี **JWT (JSON Web Token)** ที่มีอายุการใช้งาน 8 ชั่วโมง
3. **บัญชีและรหัสผ่าน (Credentials):**
   * **User / Username:** ไม่จำเป็นต้องพิมพ์ Username (ระบบจะกำหนดสิทธิ์เป็น Role: `admin` ให้อัตโนมัติเมื่อรหัสผ่านถูกต้อง)
   * **Password (รหัสผ่านปัจจุบัน):** **`OAA@spu2568!`** *(สามารถปรับเปลี่ยนได้ในไฟล์ `.env` ของหลังบ้าน)*
4. **สิ่งที่จะเกิดขึ้นหลัง Login สำเร็จ:**
   * แถบ **"📋 รายชื่อที่ค้นหาและบันทึกไว้"** จะปรากฏขึ้นมาที่ด้านบนของฟอร์ม
   * สามารถใช้ฟังก์ชันค้นหารายชื่ออาจารย์, ปุ่ม **`👁️ แสดงตัวอย่าง`** (ดูตัวอย่างแบบฟอร์มทางการ), ปุ่ม **`📥 ดาวน์โหลด PDF`** (เซฟเอกสาร PDF ลงเครื่อง), ปุ่ม **`✏️ โหลดฟอร์ม`** (โหลดกลับมาแก้ไข), และปุ่ม **`🗑️ ลบ`** ได้ทันที
